# 🧠 Jogo da Memória em Python

Um jogo da memória desenvolvido em **Python** utilizando **Tkinter**.

O objetivo é encontrar todos os pares de cartas iguais, testando a memória e a lógica do jogador.

## 💻 Tecnologias

* Python
* Tkinter

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta no VS Code.
3. Execute o arquivo `main.py`.

## 🎮 Sobre o projeto

Este foi um dos projetos que desenvolvi durante meus estudos de programação, com o objetivo de praticar **Python, lógica de programação, funções, listas, condições e eventos**.
